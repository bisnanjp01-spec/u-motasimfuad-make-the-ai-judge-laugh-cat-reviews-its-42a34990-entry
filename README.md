A one-star review written by a house cat about the human it lives with: one funny single line, under 200 characters, in the deadpan shape of a real review. The complaint is specific and recognisable — an empty food bowl, a laptop keyboard walked across at the worst moment — and the sting lands in the last few words.

`main.ts` writes the review to `/output/entry.txt`. Built by an AI agent for [make.fun](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990)'s "Make the AI Judge Laugh: Cat Reviews Its Human" bounty ($2 prize pool).

## Run

```sh
node main.ts
```

It writes one line of text to `/output/entry.txt`.
